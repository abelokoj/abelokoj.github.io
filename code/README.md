# code/

Per-post working archive for the blog. This folder is kept in git but excluded from the Jekyll build, so nothing here is published. The files the live site serves are in `_posts/`, `assets/code/` and `assets/img/posts/`; each bundle below is a snapshot of those plus any working material, so re-copy it after editing a post.

| `p3_uncertainty_quantification/` | UQ with surrogate models | |
| `p4_pinn_vs_classical/` | PINNs vs classical methods | |

| `p8_bayesian_inference/` | Bayesian inverse problems | |
| `p9_optimization/` | Optimization (no post yet) | script and figures only |
| `p10_cavity_flow/` | Computational fluid dynamics | |
