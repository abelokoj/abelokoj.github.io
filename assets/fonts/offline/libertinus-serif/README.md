# Libertinus Serif offline fonts

Downloaded from the [official Libertinus v7.051 release](https://github.com/alerque/libertinus/releases/tag/v7.051), the latest GitHub release checked on October 11, 2026.

Source archive: [Libertinus-7.051.zip](https://github.com/alerque/libertinus/releases/download/v7.051/Libertinus-7.051.zip).

Unmodified font files are stored in `otf/` (OpenType) and `woff2/` (compressed webfonts). Both folders include Regular, Italic, Semibold, Semibold Italic, Bold, Bold Italic, and the companion Serif Display and Serif Initials faces.

The SIL Open Font License and copyright notices are preserved in `OFL.txt`.

The website loads the six main WOFF2 faces locally for headings and prose. Code retains its Maple Mono font stack, equations use the Libertinus Math SVG renderer described in `../libertinus-math/README.md`, and the separately styled Resume page retains its sans-serif font. The OTF, Display, and Initials files remain available for offline use.
