# Libertinus Math offline font

Unmodified `LibertinusMath-Regular.otf` and `LibertinusMath-Regular.woff2` from the [official Libertinus v7.051 release](https://github.com/alerque/libertinus/releases/tag/v7.051), added on October 11, 2026.

Source archive: [Libertinus-7.051.zip](https://github.com/alerque/libertinus/releases/download/v7.051/Libertinus-7.051.zip).

Libertinus Math is the OpenType math companion to Libertinus Serif. Its SIL Open Font License and copyright notices are preserved in `OFL.txt`.

These original OTF and WOFF2 files are retained for offline use. The website renders equations using a MathJax 4 SVG bundle containing converted Libertinus Serif and Libertinus Math glyph data, rather than applying the raw WOFF2 font to MathJax's layout.

The renderer comes from [dgleich/mathjax-fonts](https://github.com/dgleich/mathjax-fonts/tree/34075ed04fe7db9153772948c2b1e0938fcd63a0/mathjax-libertinus), pinned to revision `34075ed04fe7db9153772948c2b1e0938fcd63a0` and loaded via jsDelivr with SHA-256 integrity validation. Its font package is OFL-1.1 licensed; MathJax itself is Apache-2.0 licensed. This is a third-party font conversion, not an official MathJax font package.
