# Splentinex offline fonts

Unmodified OpenType fonts downloaded from the [author's repository](https://github.com/dbenjaminmiller/splentinex) at revision `7be9d8696b1981d55caeba341a25767d92032aca` on October 9, 2026.

Included faces: Regular, Italic, Bold, and Bold Italic. Their SIL Open Font License 1.1 and copyright notices are preserved in `COPYING.txt`.

These files are retained as an offline copy for future use and are not currently loaded by the site. Headings and prose use Libertinus Serif. Code retains its Maple Mono font stack, equations retain the math renderer's fonts, and the separately styled Resume page retains its sans-serif font.
